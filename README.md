### 소개

html, css 파일의 웹 접근성을 검사합니다.

> html
- `img` 태그에 `src`, `alt` 속성 여부 검사
- `table` 태그에 `caption`이나 `summary` 속성 여부 검사
- `frame`, `iframe` 태그에 `title` 속성 여부 검사
- `lang` 언어 설정 여부 검사
- `<meata name='viewport'>` 여부 검사
- 비디오, 오디오에 autoplay 속성 여부 검사 (없어야 함)
- 멀티미디어 콘텐츠에 track 태그 여부 (자막, 설명 등을 제공하기 위함)
  
> css
- 텍스트 단위 : `em`, `rem` 사용 여부
- 텍스트 간격 : `line-height`, `letter-spacing`, `word-spacing` 여부, 값 확인
